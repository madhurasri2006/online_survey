# Online Survey and Feedback Management System

## Project Description
A web-based application that allows users to submit feedback about sessions and helps administrators manage and analyze the collected feedback.

## Technologies Used
- React.js
- Vite
- Node.js
- Express.js
- MongoDB Atlas
- Axios
- CSS

## Features
- Submit feedback through a survey form
- View all submitted feedback
- Edit existing feedback
- Delete feedback
- Search feedback records
- Filter feedback by department
- View rating and department summaries
- Export feedback data as a CSV file
